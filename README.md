# Food Donation Tracking DApp

A decentralized application for tracking and verifying food donations on the Stacks blockchain.

## 🚀 Features

- Create and track donations
- Verify received donations
- Track donor and recipient statistics
- Secure admin controls
- Real-time status updates

## 🛠️ Technical Details

### Security Features
- Input validation for donation amounts
- Access control for verification
- Admin role management
- Protected state transitions

### Optimizations
- Efficient data storage using maps
- Optimized verification process
- Minimal gas consumption

## 📋 Usage Instructions

1. Deploy the contract:
```bash
clarinet contract deploy
```

2. Initialize the contract:
```bash
clarinet contract call initialize-contract
```

3. Create a donation:
```bash
clarinet contract call create-donation
```

## 🧪 Testing

Run the test suite:
```bash
clarinet test
```
